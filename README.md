# TeleLoopSpeedUp
Exponentially speeds up the teleporter by a multiplier (default 2x) whenever you loop.

This mod exists because I believe buying or forgetting to buy Focused Convergence every run, once you start looping, is a slog.

# Building the project:

1. Check `~/TeleLoopSpeedUp/TeleLoopSpeedUp.csproj` for build dependencies under game-libs & libs.

2. run `dotnet build TeleLoopSpeedUp.slnx`
